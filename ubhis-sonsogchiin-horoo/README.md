# ҮБХИС-ийн Сонсогчийн хороог шинээр байгуулах — бүтэц, зохион байгуулалтын санал

**Файлууд:**
- `ubhis_sonsogchiin_horoo_sanal.docx` — бүтэц, зохион байгуулалтын санал (A4, ≈25 хуудас)
- `ubhis_sonsogchiin_horoo_yalgah_temdeg.docx` — албан тушаалын ялгах тэмдэг, шагналын тэмдгийн санал (A4, ≈22 хуудас, 9 загварын зурагтай)
- `ubhis_sukhbaatar_nerjmit_shagnal.docx` — Д.Сүхбаатар жанжны нэрэмжит шагналын журам, тэмдэг, өргөмжлөлийн загвар (A4, 10 хуудас)

Олон улсын цэргийн их, дээд сургуулиудын (USMA, USNA, USAFA, RMC Канад, Сэндхерст, Японы Батлан хамгаалахын академи, KMA, Энэтхэгийн NDA, ОХУ) сонсогчийн байгууллагыг харьцуулан судалж, ҮБХИС-ийн 4 жилийн сургалтын тогтолцоонд тохирсон Сонсогчийн хорооны бүтцийг санал болгосон баримт бичиг.

## Агуулга
1. Удиртгал — үндэслэл, зорилго, хүрэх үр дүн, арга зүй
2. Олон улсын 9 сургуулийн туршлага
3. Харьцуулсан дүн шинжилгээ (2 харьцуулсан хүснэгт, 8 нийтлэг зарчим)
4. Бүтцийн санал — бүтцийн схем (3 батальон, 12 рот, 48 салаа), албан тушаал, 5 зөвлөл, 4 жилийн манлайллын шат, ротацийн тооцоо, шалгаруулалт, эрх хэмжээний матриц, өдөр тутмын хуваарь, нэр төр, эх оронч хүмүүжил, нэрэмжит ротууд, үнэлгээ
5. Хэрэгжүүлэх үе шат (2026–2031)
6. Эрсдэл, шалгуур үзүүлэлт
7. Дүгнэлт, санал
- Хавсралт: журмын төслийн бүтэц, нэр томъёоны харьцуулалт, эх сурвалж

## Ялгах тэмдэг, шагналын тэмдгийн санал (нэмэлт баримт)
- Олон улсын туршлага: USNA (зураасны систем, Color Company), USAFA (семестрийн 4 жагсаалтын тэмдэг), USMA, RMC, Сэндхерст (Хүндэт сэлэм), NDA Энэтхэг (медаль, аваргын туг), ОХУ (курсийн тэмдэг)
- Мөрдөсний бүрээс: 4-р курс — алтлаг ромб (тоо = түвшин, алтан хүрээ = дарга), 2–3-р курс — мөнгөлөг шеврон
- Курсийн, хорооны, нэрэмжит ротын тэмдэг; жижүүрийн бугуйвч
- Шагнал: семестрийн жагсаалт, жилийн/тусгай, нэгжийн, төгсөлтийн; олгох, хураах, зүүх журам, эрэмбэ
- Загварын зургууд: `images/*.png` (SVG эх нь мөн `images/`-д)

## Д.Сүхбаатар жанжны нэрэмжит шагнал
- Сонсогчийн хорооны хамгийн дээд шагнал: жилд 1, Зэвсэгт хүчний өдөр (3.18) олгоно
- Шалгуур (6 заавал + давуу тал, 100 оноо), 5 үе шаттай шалгаруулалт, бүрдэл, зүүх, хураах журам
- Бамбай хэлбэрийн тэмдэг (50 × 62 мм): хөх дэвсгэр, улаан хүрээ, алхан хээ, сүлдний жад, загалмайлсан илд, «Д.СҮХБААТАР» тууз, «1921»
- Төрийн «Сүхбаатарын одон»-оос ялгах: дугуй биш, хөрөггүй, «одон» гэж нэрлэхгүй, баруун энгэрт

## Дахин үүсгэх
```bash
node src/build.js              # → ubhis_sonsogchiin_horoo_sanal.docx
node src/insignia_figures.js   # → images/*.png (Playwright/Chromium шаардлагатай)
node src/build_insignia.js     # → ubhis_sonsogchiin_horoo_yalgah_temdeg.docx
node src/sukhbaatar_figures.js # → images/sb_*.png
node src/build_sukhbaatar.js   # → ubhis_sukhbaatar_nerjmit_shagnal.docx
```
Нэрэмжит ротын хүснэгтийг `../ubhis-11-baatar/src/heroes.json`-оос уншина.

## Анхаарах
- Word дээр нээхэд гарчгийн талбарыг шинэчлэх эсэхийг асууна — «Yes» дарна.
- Гадаадын сургуулиудын тоо баримт ойролцоо. ҮБХИС-ийн одоогийн сонсогчийн тоо, бүтцийг сургуулийн албанаас тодруулж 4.2-ын тооцоог шинэчлэх шаардлагатай.
