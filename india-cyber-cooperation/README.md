# Монгол–Энэтхэгийн кибер аюулгүй байдлын хамтын ажиллагаа — PPT илтгэл

**Файл:** `india_mongolia_cyber_cooperation.pptx` (26 слайд, 16:9, англи хэлээр, илтгэгчийн тэмдэглэлтэй)

Энэтхэг–Монголын Батлан хамгаалах яамд хоорондын 14 дэх удаагийн зөвлөлдөх уулзалтын (JWG) хүрээнд БНЭУ-ын төлөөлөгчид ҮБХИС-ийн Цэргийн нэгдсэн сургуулийн Кибер аюулгүй байдлын тэнхимд зочлох үед танилцуулах илтгэл. Хамтын ажиллагааны түүх, 2015 оны санамж бичгээс 2022 оны нээлт хүртэл, Энэтхэгийн хөрөнгө оруулалт, 2022–2026 онд хийж хэрэгжүүлсэн ажлын үр дүн (тоо баримт, график, зураг), цаашдын хамтын ажиллагааны санал (ҮБХИС-ийн 2026.10.09-ний 01/1171 тоот албан бичиг) гэсэн логик дарааллаар бүтээсэн.

**Хэл:** Төлөөлөгчид Энэтхэгийн БХЯ-ны албан тушаалтнууд тул слайд, илтгэгчийн англи текстийг англиар, слайд бүрийн тэмдэглэлийн эхний мөрөнд «МН:» гэсэн монгол товч заавар оруулсан. Агуулга бүхэлдээ `src/data.js` файлд тусгаарлагдсан тул монгол хувилбар хийхэд зөвхөн тэр файлыг орчуулаад дахин үүсгэнэ.

**Хугацаа:** 20–25 минут. Хэсгийн хуудас 4, нүүр/төгсгөл 2, агуулгын слайд 20 → слайд тус бүр ≈1–1.2 минут. Тэмдэглэл дэх англи текстийг уншвал ≈23 минут.

## Дахин үүсгэх

```bash
cd src && npm install pptxgenjs sharp react react-dom react-icons
SKILL_DIR=<pptx skill directory> NODE_PATH=$PWD/node_modules node build.js ../india_mongolia_cyber_cooperation.pptx
```

`src/data.js` — бүх текст, тоо, хүснэгт, график, замын зургийн өгөгдөл; `src/build.js` — загвар, дизайн, слайдын бүтэц. Өнгө: хөх (Монгол), улбар шар (Энэтхэг), ногоон (хамтарсан) — график, Гант, он дарааллын тэмдэглэгээнд ижил утгаар ашигласан.
