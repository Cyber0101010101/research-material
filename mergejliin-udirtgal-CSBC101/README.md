Кибер аюулгүй байдлын бакалаврын хөтөлбөрийн (индекс 103103) **I курсын намрын улирал (1А)**-д заагдах
«Мэргэжлийн удиртгал» (CSBC101, 2 кредит) хичээлийн бүрэн материал.

| Хэлбэр | Цаг | Бүтэц |
|---|---|---|
| Лекц | 16 | 2 цагаар 8 удаа |
| Дадлага | 32 | 4 цагаар 8 удаа |
| Бие даалт | 48 | 2 бие даалтын ажил + тогтмол даалгавар |
| **Нийт** | **96** | **2 кредит** |

## Лекц ба дадлагын сэдэв

| № | Лекц (2 цаг) | Дадлага (4 цаг) |
|---|---|---|
| 1 | Кибер аюулгүй байдал — мэргэжлийн танилцуулга | Лабораторийн орчинтой танилцах ба хувийн кибер аюулгүй байдал |
| 2 | Кибер орчны аюул занал ба хамгаалалтын зарчим | Аюул заналыг таних: фишинг ба нууц үгийн аюулгүй байдал |
| 3 | Мэдлэгийн салбар, мэргэших чиглэл ба ажлын үүрэг | Мэргэших чиглэлүүдийг турших: станцын дадлага |
| 4 | Хөтөлбөрийн бүтэц: хичээлүүдийн үүрэг ба уялдаа холбоо | Хөтөлбөрийн зураглал: хичээл, чадамж, карьерын уялдаа |
| 5 | Их сургуульд үр дүнтэй суралцах арга барил | Суралцах хэрэгслээ бүрдүүлэх: виртуал машин, Linux, Git |
| 6 | Хууль эрх зүй, мэргэжлийн ёс зүй ба хариуцлага | Хууль, ёс зүйн кейс шинжилгээ ба ангийн ёс зүйн гэрээ |
| 7 | Карьерын зураглал: ажлын байр, албан тушаал, сертификат | Ажлын зар шинжлэх ба карьерын зураглал боловсруулах |
| 8 | Тасралтгүй суралцахуй ба хувийн хөгжлийн төлөвлөгөө | Анхан шатны CTF ба хувийн хөгжлийн төлөвлөгөө хамгаалах |

## Үнэлгээ (100 оноо)
Ирц, идэвх 10 · Дадлага 8×5 = 40 · Бие даалт 1 (эссэ) 8 · Бие даалт 2 (карьерын зураглал, IDP) 12 · Явцын шалгалт 2×15 = 30.

## Анхаарах зүйл
- Хуулийн зүйл, бүлгийн дугаарыг (ж: Эрүүгийн хуулийн 26 дугаар бүлэг) хичээл эхлэхээс өмнө legalinfo.mn дээрх хамгийн сүүлийн хувилбартай тулгаж шалгана уу.
- Багшийн мэдээлэл, батлах/хянах албан тушаалтныг «Тоон ул мөрийн шинжилгээ» хөтөлбөрөөс авсан; шаардлагатай бол засна уу.
- Лекцийн удирдах төлөвлөгөөнд хичээл заах огноо, сонсогчийн тоо, батлах огноог «……» гэж хоосон үлдээсэн; хуваарь гарсны дараа бөглөнө үү. «Төлөвлөсөн» хэсэгт хичээл заах багшийг бичсэн.
- Онооны хуваарилалт, явцын шалгалтын тоо нь санал болгож буй хувилбар; тэнхимийн журамд нийцүүлж өөрчилж болно.

## Дахин үүсгэх

```bash
cd src
npm install
npm run syllabus && npm run practice
SKILL_DIR=<pptx skill directory> npm run slides   # theme-ийн өнгө бичихэд SKILL_DIR шаардлагатай

# Лекцийн удирдах төлөвлөгөө: тэнхимийн загвар docx-ыг бөглөнө
node -e "console.log(JSON.stringify(require('./lecture_plans')))" > plans.json
python3 fill_lecture_plans.py <загвар.docx> plans.json ../lektsiin_udirdah_tuluvluguu
```
