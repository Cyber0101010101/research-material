# CSBC101 «Мэргэжлийн удиртгал» — Moodle SCORM багц

8 лекц тус бүрийг **Moodle-д шууд ачаалж болох SCORM 1.2 багц** (.zip) болгон бэлтгэв. Лекц бүр интерактив агуулга, **практикт суурилсан үнэлгээний дасгалуудтай** (фишинг таних, Linux терминал, URL задлах, ангилах, нөхцөл байдлын шийдвэр гэх мэт).

## Файлууд
| Хавтас/файл | Тайлбар |
|---|---|
| `dist/CSBC101_Lekts_01…08_SCORM.zip` | Moodle-д ачаалах 8 багц. Нэг бүр нь бие даасан SCORM 1.2 SCO. |
| `player/` | Тоглуулагчийн эх код: `engine.js` (логик), `player.js` (UI, SCORM холболт), `style.css`, `index.html` |
| `content/lesson1…8.js` | Лекц бүрийн агуулга, дасгалын өгөгдөл (`window.LESSON`) |
| `build_scorm.js` | Нэг лекцийг багцын файл болгоно |
| `build_all.sh` | 8 багцыг бүгдийг нь .zip болгоно |
| `tests/validate.js` | Агуулгын бүтцийн шалгагч (browser-гүй) |
| `tests/run.js` | Headless Chromium-аар бүх дасгалыг бодож, SCORM оноо бүртгэгдэхийг шалгана |
| `AUTHORING.md` | Агуулга нэмэх, засах лавлах (блокийн бүх төрөл) |

## Moodle-д ачаалах
1. Хичээл дотор: **Идэвх нэмэх → SCORM багц**.
2. «Багцын файл» талбарт `CSBC101_Lekts_0N_SCORM.zip`-ийг чирч оруулна.
3. Хадгалж, нээнэ. Оноо (0–100), тэнцсэн эсэх (passed/failed) нь Moodle-ийн **Дүнгийн дэвтэрт** автоматаар бүртгэгдэнэ.
   - Санал болгох тохиргоо: *Grading method = Highest attempt*, *Attempts = Unlimited*, *Display package = New window эсвэл Current window*.
4. Багц бүр тусдаа SCO тул 8 идэвх болгон нэмнэ (эсвэл 8 долоо хоногт тараана).

## Үнэлгээ хэрхэн ажилладаг
- Лекц бүр **6–9 практик дасгалтай**, дасгал бүр оноотой. Нийт онооны **%**-ийг `cmi.core.score.raw` (0–100) болгон LMS-д илгээнэ.
- **Тэнцэх босго 70%**. Бүх хэсгийг үзэж, бүх дасгалыг гүйцэтгэсний дараа «Дуусгах» идэвхжинэ.
- Дасгалын **эхний оролдлого** оноонд тооцогдоно; дараа нь хичээллэх зорилгоор хэдэн ч удаа давтаж болно.
- Явцыг `cmi.suspend_data`-д хадгалдаг тул сонсогч таслаад буцаж орвол үргэлжлүүлнэ.
- Дасгал бүр `cmi.interactions`-д бичигддэг тул багш хариултын түвшинг харж болно.

## Дасгалын төрлүүд (практикт суурилсан)
фишинг и-мэйл/пост дахь сэжигтэй хэсгийг тэмдэглэх · Linux терминал симулятор (grep/awk/sort/uniq/sha256sum/exiftool) · URL задлан шинжлэх · нууц үгийн энтропи хэмжих · кодчилол тайлах (Base64/ROT13/Caesar) · ангилах · дараалуулах · харгалзуулах · нөхөх · олон алхамт нөхцөл байдлын шийдвэр · нэг/олон сонголттой асуулт.

Бүх логик (SHA-256, терминал, URL задлагч г.м.) нь **офлайн, браузер дотор** ажиллана — гадны сан, сервер шаардахгүй.

## Дахин үүсгэх / агуулга засах
```bash
cd scorm
# агуулгыг content/lessonN.js дотор засна (AUTHORING.md-г үз)
node tests/validate.js content/lesson2.js      # бүтэц шалгах
node tests/run.js content/lesson2.js           # headless функциональ тест (Chromium)
bash build_all.sh dist                          # 8 .zip-ийг дахин үүсгэх
```
