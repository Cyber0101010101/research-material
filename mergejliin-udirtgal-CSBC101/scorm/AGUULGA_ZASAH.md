# CSBC101 SCORM — агуулгыг хэрхэн засах вэ (энгийн гарын авлага)

Энэ бол лекцийн **агуулга, асуулт, хариултыг** өөрөө засах алхамчилсан заавар. Техникийн гүнзгий мэдлэг шаардахгүй — текст засч, нэг команд ажиллуулахад л багц шинэчлэгдэнэ.

---

## 1. Юуг хаанаас засах вэ

Лекц бүрийн бүх агуулга **нэг файлд** байна:

```
scorm/content/lesson1.js   → Лекц 1
scorm/content/lesson2.js   → Лекц 2
...
scorm/content/lesson8.js   → Лекц 8
```

Эдгээр нь энгийн текст файл. Notepad++, VS Code, эсвэл ямар ч текст засварлагчаар нээж болно. Монгол үсэг (кирилл) шууд бичнэ.

> **Заавал:** файлыг **UTF-8** кодчилолоор хадгална (ихэнх засварлагч анхдагчаар ийм). Word-оор БИТГИЙ нээ — текст засварлагч ашигла.

---

## 2. Засвар хийх үндсэн дүрэм

- Юмс `'ганц хашилт'` эсвэл `"давхар хашилт"` дотор бичигдсэн байна — **хашилтны дотор** текстийг л сольж засна.
- Мөр бүрийн төгсгөлд **таслал `,`** байдаг — түүнийг бүү устга.
- `{ }` хаалт, `[ ]` хаалтыг тэнцүү үлдээ (нээснийг хаа).
- Текст дотор `**тод**`, `*налуу*`, `` `код` `` гэж бичвэл тодруулж харагдана. Мөр таслахдаа `\n`.

---

## 3. Түгээмэл засварууд

### 3.1 Энгийн текст (тайлбар, гарчиг) солих
Жишээ — лекцийн нэрийг солих:
```js
title: 'Кибер аюулгүй байдал — мэргэжлийн танилцуулга',
```
Хашилтны доторх текстийг сольж бичнэ. Болоо.

### 3.2 Сонгох асуултын (mcq) хариулт эсвэл тайлбарыг засах
```js
{ type:'mcq', id:'l1_cia1', points:6, title:'Аль шинж зөрчигдсөн бэ?',
  q:'DDoS халдлагад аль шинж зөрчигдсөн бэ?',
  options:[
    { t:'Нууцлал', fb:'Мэдээлэл задарсан тухай яриагүй.' },
    { t:'Хүртээмж', correct:true, fb:'Зөв — систем хэрэгтэй үедээ ажиллаагүй.' },
  ],
  explain:'DDoS нь үйлчилгээг хүртээмжгүй болгодог.' },
```
- Асуултын текст: `q:` -ийн дараах хашилт.
- Сонголтын текст: `t:` -ийн дараах хашилт.
- **Зөв хариулт**: `correct:true` гэж тэмдэглэсэн сонголт. Өөр сонголтыг зөв болгохыг хүсвэл хуучнаас нь `correct:true`-г устгаад, шинэ сонголтод `correct:true` нэм.
- Тайлбар: `fb:` (сонголт тус бүрийн), `explain:` (ерөнхий).

### 3.3 Ангилах дасгал (classify) засах
```js
{ type:'classify', id:'l1_space', points:8, title:'...',
  q:'Жишээ бүрийг зөв ангилалд оноо.',
  categories:['Төхөөрөмж','Программ','Өгөгдөл','Хүн/процесс'],
  items:[
    { t:'Сүлжээний чиглүүлэгч', cat:0 },
    { t:'Ubuntu үйлдлийн систем', cat:1 },
  ] },
```
- `categories` — ангиллын нэрс (жагсаалт).
- `cat:` — тухайн зүйл аль ангилалд багтахыг заана. **0 = эхний** ангилал, 1 = хоёр дахь, гэх мэтээр тоолно.
- Шинэ зүйл нэмэх: `{ t:'шинэ зүйл', cat:2 },` гэсэн мөрийг `items` дотор нэм.

### 3.4 Дараалуулах дасгал (order) засах
```js
{ type:'order', id:'l2_killchain', points:10, title:'...',
  q:'Зөв дарааллаар байрлуулна уу.',
  items:['Эхнийх','Хоёр дахь','Гурав дахь'] },
```
- `items`-ийг **зөв дарааллаар** бич (систем автоматаар холиод, суралцагч зөв эрэмбэлнэ).

### 3.5 Харгалзуулах дасгал (match) засах
```js
{ type:'match', id:'l2_actors', points:8, title:'...',
  q:'Харгалзуулна уу.',
  pairs:[
    { l:'Зүүн тал', r:'Баруун тал (зөв хос)' },
  ] },
```
- `l` = зүүн, `r` = баруун. Хос нь **зөв харгалзаатай** байхаар бич.

### 3.6 Нөхцөл байдлын дасгал (scenario) засах
```js
{ type:'scenario', id:'l1_hygiene', points:12, title:'...',
  steps:[
    { text:'Нөхцөл байдлын тайлбар?',
      choices:[
        { t:'Зөв сонголт', s:1, fb:'✓ Яагаад зөв.' },
        { t:'Буруу сонголт', s:0, fb:'✗ Яагаад буруу.' },
      ] },
  ] },
```
- `s` = оноо: **1 = бүрэн зөв**, 0 = буруу, 0.4 гэх мэт = хагас зөв.
- Алхам (`steps`) бүрт **дор хаяж нэг `s:1`** сонголт байх ёстой.

### 3.7 Оноог өөрчлөх
Аль ч дасгал дээрх `points:8` гэсэн тоог сольж, дасгалын жинг өөрчилнө. Нийт оноо автоматаар дахин тооцогдож, 100%-д хувирна.

### 3.8 Фишинг таних дасгал (hotspot) засах
```js
body:[
  ['Энгийн текст ', { t:'сэжигтэй хэсэг', hot:true, fb:'Яагаад сэжигтэй.' }, ' үргэлжлэл'],
]
```
- `hot:true` = сэжигтэй (суралцагч олох ёстой). `hot:false` = хэвийн (тэмдэглэвэл торгууль).
- Текст доторх сэжигтэй хэсгийг `{ t:'...', hot:true, fb:'...' }` болгон бичнэ.

---

## 4. Зассаныхаа дараа — заавал шалгах ба багц дахин үүсгэх

Терминал (эсвэл Git Bash) нээж, `scorm` хавтас руу орно:

```bash
cd scorm

# 1) Бүтэц зөв эсэхийг шалгах (жишээ: лекц 1)
node tests/validate.js content/lesson1.js

# 2) Бүх дасгал ажиллаж, оноо зөв бүртгэгдэхийг шалгах (Chromium хэрэгтэй)
node tests/run.js content/lesson1.js

# 3) Бүх багцыг (.zip) дахин үүсгэх
bash build_all.sh
```

- `validate.js` нь алдаа (жишээ: таслал дутуу, зөв хариулт байхгүй) заана. **0 алдаа** гартал зас.
- `build_all.sh` нь `scorm/dist/` дотор 8 шинэ .zip үүсгэнэ.
- Шинэ .zip-ийг Moodle дээр хуучин багцаа **шинэчлэх** (эсвэл дахин ачаалах) замаар суулгана.

---

## 5. Анхаарах зүйл

- Нэг зүйл сольсны дараа **тухайн лекцийн validate-ийг** ажиллуулж, алдаа байхгүйг батал.
- Зөв хариулт сольсон бол **бодит зөв эсэхийг** нягтал (жишээ: classify-д `cat` индекс зөв ангилалд заасан эсэх).
- id (`l1_cia1` гэх мэт)-ийг БҮҮ давхардуул — дасгал нэмбэл шинэ, давтагдашгүй id өг.
- Хэрэв засвар ээдрээтэй бол (жишээ шинэ терминал дасгал нэмэх), `scorm/AUTHORING.md` файлд блокийн бүх төрлийн бүрэн жишээ, дүрэм бий.

---

## 6. Хэн нэгэнд даалгах бол

Текст засварлах мэдлэггүй хүнд даалгахаар бол: лекц бүрийн агуулгыг энгийн Word/Excel хүснэгтээр гаргаж өгөөд, бөглүүлсний дараа `lessonN.js`-д буулгах нь илүү найдвартай. Хүсвэл энэ хэлбэрийн загвар бэлдэж өгч болно.
