# CSBC101 SCORM лекц бичих лавлах (блокийн төрлүүд)

Файл бүр нэг `window.LESSON = { ... }` объект экспортлоно. UTF-8, монгол хэл. Гадны сан хэрэглэхгүй.

## Дээд түвшний бүтэц
```js
window.LESSON = {
  id: 'csbc101_lN',          // N = лекцийн дугаар
  num: N,
  title: 'Лекцийн нэр',
  passPercent: 70,
  badge: { icon: '🎖️', name: 'Энгэрийн тэмдгийн нэр', text: 'Юунд хүрснийг богино өгүүлбэр' },
  summary: ['гол санаа 1', 'гол санаа 2', 'гол санаа 3', ...],   // 3-5, markdown зөвшөөрнө
  next: 'Дараагийн дадлагад юу хийх тухай 1-2 өгүүлбэр',
  screens: [ /* 8 хэсэг */ ],
};
```

## Шаардлага (ЗААВАЛ)
- **8 хэсэг (screen)** байх. Эхний хэсэг танилцуулга (poll-той), сүүлийн хэсэг нэгтгэл/нөхцөл байдал.
- Нийт **6–9 оноотой дасгал (exercise)**, нийт оноо **≥ 60**. Оноо нь блок дээр `points:` талбараар.
- Дасгал бүрт **давтагдашгүй `id`** (`lN_xxx` хэлбэрээр, N=лекцийн №), `points`, `title` ЗААВАЛ.
- Дасгалууд **практикт суурилсан** байх: ангилах, дараалуулах, терминал, фишинг таних, нөхцөл байдлын шийдвэр гэх мэт. Зүгээр нэр томьёо цээжлүүлэх ганц сонголттой асуулт БИШ.
- Хариултын тайлбар (`explain`, сонголтын `fb`) бичиж, сурагчид **яагаад** зөв/буруу болохыг ойлгуул.
- Markdown: `**тод**`, `*налуу*`, `` `код` ``, мөр таслах `\n`. (Зөвхөн эдгээр.)

## Агуулгын блокууд (оноогүй)
```js
{ type:'text', h:'гарчиг?', p:['догол мөр', ...], bullets:['цэг', ...] }   // h, p, bullets бүгд заавал биш
{ type:'callout', variant:'info|tip|warn|fact', h:'гарчиг?', text:'...' }
{ type:'cards', h:'?', lead:'?', cols:2|3|4, items:[{icon:'📱', h:'нэр', sub:'англи?', t:'тайлбар'}] }
{ type:'cards', flip:true, cols:3, items:[{icon:'🔒', h:'нүүр гарчиг', t:'нүүр', back:'ар талын текст'}] }  // эргэдэг карт
{ type:'stats', h:'?', items:[{n:'68%', l:'тайлбар', s:'эх сурвалж?'}] }
{ type:'timeline', h:'?', items:[{y:'2021', h:'богино гарчиг?', t:'дэлгэрэнгүй (дарж нээнэ)'}] }
{ type:'accordion', h:'?', items:[{h:'асуулт/гарчиг', t:'хариулт' эсвэл ['догол1','догол2']}] }
{ type:'tabs', h:'?', items:[{h:'таб нэр', p:['...'], bullets:['...']}] }
{ type:'reveal', h:'Бодоод үз', q:'асуулт', a:'нуугдсан хариулт' }         // оноогүй, бодох асуулт
{ type:'poll', q:'санал асуулга', options:['a','b'], after:'хариу өгсний дараах текст' }  // оноогүй
{ type:'quote', text:'ишлэл', by:'хэн хэлсэн?' }
{ type:'tool', tool:'cipher|hash|password|url', h:'?', text:'?', sample:'url/cipher-д анхны утга', shift:3 }
```
Хэрэгслүүд: `cipher` (Base64/ROT13/Caesar/Hex тайлагч), `hash` (SHA-256), `password` (энтропи хэмжигч), `url` (URL задлагч). Эдгээр нь **бодит ажилладаг** тул дасгалын өмнө тавьж, сурагч туршаад дараа нь дасгал хийнэ.

## Дасгалын блокууд (оноотой — id, points, title ЗААВАЛ)

### mcq — сонгох асуулт (нэг буюу олон зөв)
```js
{ type:'mcq', id:'l3_x', points:6, title:'...', q:'асуулт',
  scenario:'нөхцөл байдал (заавал биш)', multi:false,  // олон зөв бол multi илүүц, систем автоматаар мэдэнэ
  options:[ {t:'хариулт', correct:true, fb:'тайлбар'}, {t:'...', fb:'яагаад буруу'} ],
  explain:'нэмэлт тайлбар' }
```
- Зөв хариултад `correct:true`. Нэгээс олон correct бол олон сонголттой болно.

### classify — ангилах (практик, маш сайн)
```js
{ type:'classify', id:'l3_x', points:8, title:'...', q:'заавар',
  categories:['Ангилал A','Ангилал B','Ангилал C'],
  items:[ {t:'зүйл', cat:0, mono:false, fb:'тайлбар?'}, ... ] }   // cat = categories доторх индекс
```

### order — дараалуулах
```js
{ type:'order', id:'l3_x', points:8, title:'...', q:'заавар', items:['1-рт','2-рт','3-рт', ...] }
```
items-ийг **зөв дарааллаар** бич (систем холиод, сурагч зөв эрэмбэлнэ).

### match — харгалзуулах
```js
{ type:'match', id:'l3_x', points:8, title:'...', q:'заавар',
  pairs:[ {l:'зүүн', r:'баруун (зөв хос)'}, ... ], extra:['нэмэлт буруу хариулт?'] }
```

### fillin — нөхөх (богино хариулт, regex зөвшөөрнө)
```js
{ type:'fillin', id:'l3_x', points:8, title:'...', q:'асуулт?', code:'кодын блок?',
  tasks:[ {q:'дэд асуулт', answers:['зөв','синоним','/^regex$/i'], hint:'сэжүүр?', show:'харуулах зөв хариулт?'} ] }
```
- `answers` дотор энгийн текст (том/жижиг үсэг, илүү зай тооцохгүй) эсвэл `/regex/flags` хэлбэрийн илэрхийлэл.

### terminal — Linux терминал симулятор + асуултууд (МАШ САЙН, практик)
```js
{ type:'terminal', id:'l3_x', points:10, title:'...', q:'даалгавар',
  banner:'эхлэлийн мессеж?', examples:['grep ... ', 'cat ...'],
  files:{ 'auth.log':'мөр1\nмөр2\n', 'data.txt':{ text:'...', meta:{'GPS Position':'...'} } },
  tasks:[ {q:'Терминалаар ол: ...', answers:['3'], hint:'grep ... | wc -l'} ] }
```
Дэмжсэн командууд: `ls, cat, head, tail, grep [-i -v -c -E], wc -l, awk '{print $N}' ($NF, $(NF-1)), cut -dX -fN, sort [-n -r], uniq [-c], sha256sum, base64 -d, exiftool, echo, pwd, whoami, help`, хоолой `|`.
- `files`-ийн утга нь текст (string) эсвэл `{text, meta:{...}}` (exiftool-д). `meta` нь exiftool гаргах талбарууд.
- tasks-ийн `answers` нь терминалд гарах **бодит хариулт** (жишээ нь IP, тоо). **ЗААВАЛ** өөрөө логикийг бодож зөв хариулт бич. Эргэлзвэл энгийн grep/wc даалгавар өг.

### hotspot — сэжигтэй хэсэг тэмдэглэх (фишинг и-мэйл/пост/зар — практик, гол дасгал)
```js
{ type:'hotspot', id:'l3_x', points:12, title:'...', q:'заавар', style:'email|post',
  header:{
    from:['текст ', {t:'сэжигтэй хэсэг', hot:true, fb:'яагаад сэжигтэй'}, ' текст'],
    to:['...'], date:['...'], subject:[{t:'...', hot:true, fb:'...'}],
    attach:[{t:'файл.exe', hot:true, fb:'...'}],       // email style
    name:'нэр', meta:'...'                               // post style
  },
  body:[ ['догол мөр ', {t:'сэжигтэй', hot:true, fb:'...'}, ' үргэлжлэл'], ['энгийн догол', {t:'сэжиггүй', hot:false, fb:'энэ хэвийн'}] ],
  verdict:{ q:'Эцсийн дүгнэлт:', options:['Хууль ёсны','Фишинг — мэдээлнэ','Мэдэхгүй'], correct:1 },
  explain:'зөв хариу үйлдэл' }
```
- `hot:true` = сэжигтэй (сурагч олох ёстой). `hot:false` = сэжиггүй боловч тэмдэглэвэл торгууль (худал эерэг). Хэдэн ч `hot:false` тавьж болно.
- Фишингийн шинж: буруу илгээгчийн домэйн, холбоосын бодит хаяг, яаруулах/айлгах, ерөнхий мэндчилгээ, `.exe` хавсралт, дүрмийн алдаа.

### scenario — нөхцөл байдлын шийдвэр (олон алхам, практик)
```js
{ type:'scenario', id:'l3_x', points:12, title:'...',
  steps:[ { text:'нөхцөл байдал', choices:[ {t:'сонголт', s:1, fb:'✓ тайлбар'}, {t:'...', s:0, fb:'✗ ...'}, {t:'...', s:0.4, fb:'~ хагас'} ] } ],
  explain:'ерөнхий дүгнэлт' }
```
- `s` = оноо (0..1). Алхам бүрт **дор хаяж нэг `s:1` (бүрэн зөв)** сонголт хэрэгтэй.

## Шалгах
Бичсэний дараа заавал ажиллуул (0 алдаа гартал):
```
node <scorm>/tests/validate.js <scorm>/content/lessonN.js
```

## Хэв маяг
- Агуулгыг лекцийн PPT-ээс аваад **интерактив** болго: ангилах, дараалуулах, кейс, терминал.
- Эхний хэсэгт poll, callout; сүүлийн хэсэгт scenario эсвэл хураангуй.
- Батлан хамгаалах, цэргийн контекстийг тохирох газарт дурд (ҮБХИС, кибер цэрэг).
- Бүх дасгал **бодит ажиллах** ёстой — зөв хариултыг нягт шалга.
